EMG Hand - Wiring Schematic

Arduino Uno · MyoWare 2 + Link Shield · PCA9685 Servo Driver · 5× SG90 · Dual-rail power
DRAFT 2026-10-10 - design review only. Nothing has been physically built or tested. Every connection below was checked against the MyoWare 2 specs, Arduino Uno R3 pinout, PCA9685 module docs, and SG90 datasheet during the parts-list verification passes. Build in the staged order and test each stage before wiring the next.
Two separate power rails - non-negotiable. The Arduino (USB/battery) powers logic + the MyoWare. The 5V/3A wall adapter powers only the servos via the PCA9685 screw terminal. The two grounds MUST be tied together (see the GND bus). Powering 5 servos from the Arduino 5V pin will brown-out or damage the board - 1.8A stall vs 400mA limit.

Staged build order
StageWire upTest
1 - Signal chainArduino + MyoWare. Power via USB.Serial monitor: flex forearm, watch A0 values swing. Run the 2-second baseline calibration (average A0 for 2 s at startup = resting baseline; flex threshold = baseline + margin). Confirm resting vs flexed separation. If A0 barely moves, turn the MyoWare gain pot clockwise with a small screwdriver.
Safety: use a laptop on battery power (charger unplugged) for serial monitoring - no mains ground path. On a desktop PC, either use a USB isolator or skip serial and debug via the onboard LED instead.
2 - Proof of conceptAdd PCA9685 + ONE servo on Ch 0. Connect the 5V/3A adapter to the V+ screw terminal (verify polarity with multimeter first - center-positive). Tie PSU (−) to Arduino GND.Flex → servo sweeps. Code needs the Adafruit_PWMServoDriver library; set the PWM frequency to 50 Hz - servos jitter at the chip's ~200 Hz default. Confirms the full EMG→motion path before committing to 5 servos.
3 - Full hand driveAdd remaining 4 servos + 470µF cap. Verify common ground with multimeter (continuity between Arduino GND pin and PSU −).All 5 channels respond. Stall-test one servo briefly - measure at the V+ screw terminal, supply must not sag below ~4.6V.
4 - MechanicsMount servos, thread tendon lines, attach to 3D-printed hand (Phase 2).Clamp servo angles in software to the hand's measured range before first full close.
Before first power-on of Stage 3: multimeter continuity check between Arduino GND pin and the 5V adapter's negative output. No beep = floating ground = servos will jitter or sit dead. Fix before proceeding.
TRS cable warning: wire colors inside cheap TRS cables are not standardized. Before connecting, use the multimeter to identify which conductor goes to tip, ring, and sleeve, then label them. Wrong order here puts 5V into the Arduino's analog input or shorts the sensor - check twice.
5V adapter polarity check: before connecting the wall adapter to the PCA9685 screw terminal, verify with the multimeter that the plug is center-positive. A center-negative adapter wired backwards will destroy the PCA9685, reverse-bias the capacitor (vent/fire risk), and potentially kill every servo on the rail. Thirty seconds with the meter prevents all of it.
